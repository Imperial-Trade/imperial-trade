# 📋 Complete Docker Setup Guide - Proper Flow & Naming

## 🏗️ **Directory Structure (VPS)**

```
/root/imperial-factory/
├── mt5-master/                    # Docker build context
│   ├── Dockerfile                 # Docker image definition
│   ├── terminal64.exe            # MT5 executable
│   ├── Terminal_XX/              # MT5 terminal directories
│   └── ...                       # Other MT5 files
│
├── config/                        # Runtime configuration
│   ├── launch_{connID1}.ini      # Dynamic launch configs (created by Go Brain)
│   ├── launch_{connID2}.ini
│   └── ...
│
└── broker-service/                # Go Brain service
    └── go-brain/
        └── main.go               # Uses: Image "imperial-mt5-worker"
```

---

## 🏷️ **Naming Conventions**

### **Docker Image:**
- **Name:** `imperial-mt5-worker`
- **Tag:** `latest` (default)
- **Full Name:** `imperial-mt5-worker:latest`

### **Docker Container:**
- **Pattern:** `worker_{connectionID}`
- **Example:** `worker_123e4567-e89b-12d3-a456-426614174000`

### **Launch Config Files:**
- **Pattern:** `launch_{connectionID}.ini`
- **Location:** `/root/imperial-factory/config/`
- **Example:** `launch_123e4567-e89b-12d3-a456-426614174000.ini`

## 🔨 **Build Process (One-Time Setup)**

### **Step 1: Prepare Dockerfile**

**Location:** `/root/imperial-factory/mt5-master/Dockerfile`

**Content:** (Already in `docs/Dockerfile.imperial-mt5-worker`)

**Build Command:**
```bash
cd /root/imperial-factory/mt5-master
docker build -t imperial-mt5-worker .
```

**Build Output:**
- Creates Docker image: `imperial-mt5-worker:latest`
- Image contains: Ubuntu 22.04, Wine, Xvfb, MT5 files

---

## 🔄 **Runtime Flow (Go Brain → Docker)**

### **1. Go Brain Receives Sync Task**

**Trigger:**
- PostgreSQL `LISTEN/NOTIFY` (realtime)
- Or polling fallback

**Code Location:** `vps-broker-service/go-brain/main.go`

---

### **2. Go Brain Creates Launch Config**

**Path:** `/root/imperial-factory/config/launch_{connID}.ini`

**Generated by:** `createLaunchIni()` function

**Content:**
```ini
[Common]
Login={decrypted_login}
Password={decrypted_password}
Server={decrypted_server}
ProxyEnable=0
CertConfirm=1

[Experts]
AllowLiveTrading=1
AllowDllImport=0
Enabled=1
AccountAndConsole=1
WebRequestEnable=1
WebRequestUrl=https://kmuoqkcxguafxulqlbmi.supabase.co

[Chart1]
Symbol=EURUSD
Period=M1
Expert=ImperialSync
```

---

### **3. Go Brain Launches Docker Container**

**Code:** `vps-broker-service/go-brain/main.go` (lines 320-343)

**Docker Command (equivalent):**
```bash
docker run -d \
  --name worker_{connID} \
  -v /root/imperial-factory/config/launch_{connID}.ini:/mt5/config/launch.ini:ro \
  imperial-mt5-worker
```

**Details:**
- **Image:** `imperial-mt5-worker` ✅
- **Container Name:** `worker_{connID}`
- **Volume Mount:** `{iniPath}:/mt5/config/launch.ini:ro`
  - Source: `/root/imperial-factory/config/launch_{connID}.ini`
  - Destination: `/mt5/config/launch.ini` (inside container)
  - Mode: `ro` (read-only)

---

### **4. Container Starts MT5**

**Entrypoint:** `/mt5/entrypoint.sh`

**Steps:**
1. Start Xvfb (virtual display): `Xvfb :99 -screen 0 1024x768x16 &`
2. Set DISPLAY: `export DISPLAY=:99`
3. Run MT5: `wine /mt5/terminal64.exe /portable /config:/mt5/config/launch.ini`

---

### **5. MT5 Syncs Trades**

**EA:** `ImperialSync.ex5` (loaded on Chart1)

**Data Flow:**
- MT5 EA → Supabase Edge Function (`mt5-sync`)
- Updates `trade_journal_entries` table
- Updates `broker_connections` status

---

### **6. Container Cleanup**

**Trigger:** Smart cleanup (after sync complete)

**Cleanup:**
- Stop container
- Remove container
- Delete launch config file: `/root/imperial-factory/config/launch_{connID}.ini`

## 🎯 **Complete Flow Diagram**

```
1. Frontend → Sync Request
   ↓
2. Supabase Edge Function → Trigger
   ↓
3. PostgreSQL NOTIFY → Go Brain
   ↓
4. Go Brain:
   - Decrypt credentials
   - Create launch_{connID}.ini
   - Launch Docker container (imperial-mt5-worker)
   ↓
5. Docker Container:
   - Mount launch.ini (read-only)
   - Start Xvfb
   - Run MT5 with config
   ↓
6. MT5 EA (ImperialSync):
   - Login to broker
   - Sync trades
   - Send to Supabase
   ↓
7. Smart Cleanup:
   - Wait for sync complete
   - Stop container
   - Remove container
   - Delete launch config
```
