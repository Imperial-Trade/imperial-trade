═══════════════════════════════════════════════════════════════════════════════
  IF YOU GET ERRORS:
═══════════════════════════════════════════════════════════════════════════════

Error: "Cannot run script"
  Fix: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Error: "Script not found"
  Fix: Check path: Test-Path C:\vps-broker-service\vps-setup\DEPLOY_NOW_SAFE.ps1

Error: "Build failed"
  Fix: cd C:\vps-broker-service && npm install && npm run build

Error: "Service not starting"
  Fix: pm2 logs imperial-trade-broker-service --lines 50
